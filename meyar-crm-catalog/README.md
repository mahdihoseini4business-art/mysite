# کاتالوگ محصول معیار (Meyar)

لندینگ / کاتالوگ چندصفحه‌ای فارسی و RTL برای CRM تخصصی تعمیرگاه خودرو.

## فایل‌ها

- `index.html` — ۱۱ صفحه پرزنت + نسخه متنی copy-only
- `styles.css` — استایل صنعتی خودرویی (آبی `#0155d2`)
- `script.js` — منوی موبایل، انیمیشن ورود، کپی متن

## اجرا

فایل `index.html` را در مرورگر باز کنید، یا:

```bash
cd meyar-crm-catalog
python3 -m http.server 8080
```

سپس به `http://localhost:8080` بروید.

## چاپ / PDF

از Print مرورگر می‌توان هر بخش را به‌صورت صفحه جدا برای PDF گرفت.
